# co-intelligence

Decide whether and how to use AI on a task, and check a draft for over-reliance before a human sees it.
The jagged frontier, centaur vs cyborg working modes, four human-accountability questions, and a reusable
self-review prompt — each of Mollick's four principles paired with the published evidence on where its
naive application breaks.

The one-line test it exists to install: **am I trusting this because it is correct, or because it sounds
confident?**

See `SKILL.md`. Framework adapted from Ethan Mollick, *Co-Intelligence* (2024) — see `ATTRIBUTION.md`.
